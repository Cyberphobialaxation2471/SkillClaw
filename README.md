## 📋 Troubleshooting common issues

If you encounter a problem, follow these suggestions to fix it.

- Program does not open: Restart your computer and try again. Ensure no other heavy software runs in the background.
- Lack of responses: Check your internet connection. The agents need the web to fetch the latest data.
- Slow performance: Close other browser tabs or programs that require a lot of memory.
- Resetting data: If you want a fresh start, go to the Settings menu and choose "Clear Learning History."

## 🔒 Privacy and safety
